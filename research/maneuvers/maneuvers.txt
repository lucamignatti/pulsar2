# Scripted sim-vs-real maneuver test.
#
# WHY: match-play comparison can only measure what the policy happens to do, and it can
# never repeat a situation. This runs a FIXED action sequence from a FIXED state in both
# venues, so any divergence is pure physics. Segments are independent (each begins with a
# state set), so errors cannot compound across maneuvers and each is scored on its own.
#
# FORMAT (whitespace-separated, '#' comments):
#   SEG   <name> <duration_ticks>
#   STATE <x> <y> <z> <pitch> <yaw> <roll> <vx> <vy> <vz> <avx> <avy> <avz> <boost>
#           position/velocity in uu, rotation in RADIANS (RLBot rotator), angvel in rad/s
#   ACT   <at_tick> <throttle> <steer> <pitch> <yaw> <roll> <jump> <boost> <handbrake>
#           applies from that tick until the next ACT in the segment
#
# Tick 0 is AFTER the state set has been confirmed applied, so both venues start identical.
# 120 ticks = 1 second.
#
# Ground rest height is z=17. Segments stay near midfield unless testing walls.
